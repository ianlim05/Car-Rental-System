# 🚗 Car Rental System (Python)

## 📌 Overview
This project is a Python-based Car Rental System developed for a car rental company in Langkawi Island. The system is designed to modernize and streamline daily operations, improve efficiency, and enhance customer service in response to increasing demand and competition.

It supports multiple user roles including Manager, Customer Service Staff, and Car Service Staff, each with specific functionalities such as managing customers, cars, rentals, and reports.

---

## ⚙️ Features

### 👨‍💼 Manager
- Secure login system
- Register, update, and delete staff
- Set and update car rental rates
- View monthly revenue reports
- Update profile

### 👥 Customer Service Staff
- Register and manage customer data
- Check car availability
- Record rental transactions
- Generate bills and receipts
- Update rental status (reserved, rented, returned)
- View and delete rental records

### 🚗 Car Service Staff
- Register and manage cars
- Update car details
- View car list
- Delete disposed cars
- Update profile

---

## 🧠 System Assumptions
- Secure authentication for all users
- Role-based access control
- Automatic ID generation for customers and records
- Strong data validation and error handling
- Accurate tracking of rentals and payments
- Automatic car availability updates

---

## 📊 Project Structure
The system is designed with clear modules:
- Manager Module
- Customer Service Staff Module
- Car Service Staff Module
- Reporting & Transaction System

## 🎯 Purpose
To simulate a real-world car rental management system that improves operational efficiency, reduces manual work, and enhances customer service experience.
